COPYCAT CROOK

のりうつって、なりきって、しれっと脱出。

魔法の世界のNPCに乗り移り、宝石を隠した「本命」を出口まで運ぶ対戦ゲーム。1対1でも、2人ずつのチームでも。ステージは3つ。友達向けのテスト版です。

Windows 版Windows 10 / 11（64bit） Mac 版macOS 12 以降（Intel / Apple シリコン）

テスト版 0.3.0（2026年10月5日）・無料。2〜4人で遊べます（ネット越しでも、同じ家のネットワークでも。ひとりでも CPU と）。日本語／English。

どんなゲーム？

泥棒：なりきって運ぶ

宝石を隠す「本命」を選び、出口へ。ほかの子に乗り移っておとりにもできる。まわりと同じように歩き、止まり、まねっこアクションをして、NPCのふりをしよう。

鬼：見破って捕まえる

一人称で群れを見張り、不自然な子に捕獲魔法。ただし人が操作している子が本命とは限らない。からっぽの子に当てても回数はへる。

攻守を交代して勝負

交代で2回ずつ泥棒をして合計点で勝負。出口から遠い子ほど高得点。1対1のほか、2人ずつの2対2も。友達とはフレンド対戦、知らない人とはランダム対戦で。

演技ボーナス：鬼の目の前で、なりきれ！

本命を操作しているときに、鬼に見られながらまねっこアクション（Space・F）を決めると「名演技」。決めるたびにゲージが1段上がり、脱出したときの点が増えます。

Lv.1　+0Lv.2　+1点MAX　+2点
  • まねっこアクションの間、本命の頭の上に輪が出ます。見られている間だけ満ちて、いっぱいになれば成功。
  • 点が増えるのは脱出できたときだけ。捕まったり時間切れになったりすると0点です。
  • 何回決めたかは鬼には見えません。わかるのは決着のときだけ。
  • でも、鬼の目の前でのまねっこアクションは見破られるリスクと隣り合わせ。おとりのまねっこアクションは数えません。

0.3.0 で増えたもの：2対2とランダム対戦

2人ずつのチームで、泥棒と鬼を交代

タイトルの「人数」で2対2を選ぶと、2人ずつのチーム戦になります。ラウンドごとにチームで泥棒と鬼を交代（各チーム2回ずつ泥棒）。

  • 泥棒は1人1つずつ本命を持ちます。相方と同じ子は選べません。相方の本命は小さい宝石とピンクの輪で見え、相方が使っている子には乗り移れません（鬼チームには見えません）。
  • 本命が脱出したら、その場でチームに点。本命が捕まった・脱出した泥棒はおとり役で続けます（少しすると近くの子へ自動で乗り移ります）。
  • 本命が2つとも片付くか、時間切れでラウンド終了。鬼は1人4回ずつ捕獲魔法を持ちます。
  • ひとりなら「あなた＋CPU の相方 vs CPU 2人」。フレンド対戦は2〜4人で、足りない席は CPU が入ります（チームは入った順に交互）。ランダム対戦も2対2を選べます。

0.2.x とは一緒に遊べません。友達も 0.3.0 を落とし直してください。

部屋コードなしで、いま遊んでいる人と対戦

タイトルの「ランダム対戦」を押すと、同じ時間に押した人と自動でつながります。ステージは毎回ランダム。

  • 20秒見つからなければ、CPU と対戦しながら待ちます（「CPUと遊んで待つ」ですぐにも）。左上に「対戦相手をさがし中」が出ている間は、裏でさがし続けています。
  • 相手が来たら CPU 戦が止まって「対戦相手が見つかった！」。4秒後に対戦が始まります。「CPU戦を続ける」も選べます。
  • 終わったら「次の相手をさがす」で続けて遊べます。
  • 相手には「フレンド対戦」のなまえ欄の名前が見えます。本名は入れないでください。
  • 1対1と2対2は別々にさがします（タイトルの「人数」の選択）。2対2は2人目が来てから少し待ち、空いた席は CPU が入ります。
  • 「あそびかた」はタイトルの右上（設定の隣）に移りました。

0.2.0 で増えたもの

  • ステージが3つに：魔女の宝物庫に、出口2つで魔法の鏡が見張る「鏡の回廊」と、ガラスの温室が並ぶ「まほう温室」が加わりました。タイトルの「ステージ」で選べます。
  • 住人が9種類に：まどうしょ・ほしフクロウ・ろうそく妖精・マンドラゴラ・花の妖精・雨雲ちゃん。どの子もまねっこアクションが2つあります。
  • 演技ボーナス：鬼に見られている間に本命でまねっこアクション（名演技）をすると、脱出したときにボーナス点。鬼には見えません。くわしく
  • チュートリアル：はじめて「GAME START」を押すと案内します。「あそびかた」からもいつでも。
  • 設定画面（音量・画面・鬼の見回しの速さ・揺れやフラッシュをへらす）と English 表示（実況のボイスも英語に）。

0.1.x とは一緒に遊べません。友達も 0.2.0 を落とし直してください。

はじめかた

Windows

  1. zip を右クリック →「すべて展開」。
  2. フォルダの中の Copycat Crook.exe をダブルクリック。
  3. 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」。

個人で作っているテスト版なので、署名がなく警告が出ます。

Mac

  1. zip をダブルクリックして展開し、CopycatCrook.app を開く。
  2. 「開けません」と出たら、システム設定 → プライバシーとセキュリティの下の方にある「このまま開く」。
  3. 同じ家のネットワークで遊ぶときは「ローカルネットワーク」の確認で「許可」。

「壊れているため開けません」と出るときは、ターミナルでこれを1回だけ：

xattr -dr com.apple.quarantine ~/Downloads/CopycatCrook.app

友達と遊ぶ

全員同じ版が必要です。「ゲームのバージョンが違います」と出たら、このページから最新版を落とし直してください。友達がいなくても、タイトルの「ランダム対戦」なら同じ時間に遊んでいる人と対戦できます。2対2で遊ぶときは、部屋をつくる前にタイトルの「人数」で2対2を選んでください（4人まで。足りない席は CPU）。

ネット越し（部屋コード）

  1. 片方がタイトルの「フレンド対戦」→ テストサーバーの「部屋をつくる」。
    AB3CD のような5文字の部屋コードが出ます。
  2. 部屋コードを LINE などで友達に送る。
  3. 友達は「フレンド対戦」→ コードを入れて「参加」。
  4. 2人そろったら、部屋を作った人が「対戦スタート！」。

同じ家のネットワーク

  1. 片方が「フレンド対戦」→ LAN の「部屋をつくる」。
  2. もう片方の「フレンド対戦」の LAN の欄に部屋が出るので押す。

出てこないときは、部屋を作った側に表示されるアドレス（例 192.168.0.10）を入れて「参加」。
